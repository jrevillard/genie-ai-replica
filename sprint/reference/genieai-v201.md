## Authentication (upstream impl = port target for Epic A)
**Pattern: `oidc-client-ts` frontend + `jose` backend + realm-as-code + Keycloak root-context behind kong.**

| Piece | Upstream path | Mechanism |
|---|---|---|
| OIDC config | `components/gov-chat-frontend/src/config/oidcConfig.js` | `getOidcConfig()`: authority `${url}/realms/${realm}`, PKCE S256, `automaticSilentRenew`, memory-only; runtime `window.APP_CONFIG.keycloak` → build fallback → defaults |
| Frontend service | `src/services/keycloakAuthService.js` | UserManager singleton: `initialize/login({returnUrl})/handleCallback/logout(id_token_hint)/signinSilent/getAccessToken`, `addSilentRenewError`→re-login |
| Vuex module | `src/store/modules/auth.js` | `{isAuthenticated, user, accessToken, isInitialized}`; user = `{iss_sub, sub, iss, email, name, roles}` from access-token claims |
| Router/guard | `src/router.js` + `src/views/CallbackView.vue` | `/callback` public; guarded routes `requiresAuth`; guard awaits `initialize` → unauthenticated → `login({returnUrl})`. **No /login route.** |
| httpService | `src/services/httpService.js` | 401 → `signinSilent()` → retry once → full Keycloak redirect; `{error:CODE, message, details}` contract |
| Runtime config | `public/config.js` + `docker-entrypoint.sh` | envsubst at container start (`window.APP_CONFIG`) — no build-time baking |
| Backend verifier | `components/gov-chat-backend/services/keycloak-auth-service.js` | `jose jwtVerify` + `createRemoteJWKSet`; lazy OIDC-discovery singleton; per-issuer JWKS cache 5-min TTL + `forceRefresh()` 2-attempt; `iss_sub` composite; does NOT check azp; `checkUserStatusInKeycloak` (UserInfo probe) |
| Middleware | `middleware/keycloak-auth-middleware.js` | PUBLIC_PATHS; provisionUser (JIT); `req.user` (Arango) + `req.claims` (JWT); `requireAdmin` reads `claims.realm_access.roles`; errors always `{error,message,details:{}}` |
| JIT provisioning | `services/user-provisioning-service.js` + `constants/jit-fields.js` | atomic UPSERT on `iss_sub`, 60s cache + in-flight locks, legacy-email migration, soft-delete reactivation; unique index `iss_sub`, non-unique `email` |
| Logout | `controllers/authController.js` + `routes/auth-routes.js` | only `POST /api/auth/logout` (session-end + audit); OIDC session dies via redirect flow |
| Keycloak proxy | `services/keycloak-proxy-service.js` | service-account (`genie-proxy-client`) → Admin API; user pass-through → Account API self-service |
| Story acceptance criteria | `_bmad-output/archived/keycloak-idp/implementation-artifacts/1-4*, 1-5*, 2-2*, 3-1*` | "memory only", "no coexistence", "no /login page", JWKS factory contract |
