Design System doc
v1.2
1. Replace hex with OKLch tokens. 907+ hardcoded colours replaced by 15 CSS tokens. Old names kept as aliases.

2. Inter font. Arial replaced with Inter + system fallback. JetBrains Mono for labels.

3. Unified spacing. Irregular values standardised to 4-8-16-24-32-48 scale.

4. Native dark mode. [data-theme="dark"] selectors. --accent-config pattern for per-deployment overrides.

5. All components migrated. 33 Vue components. Chart libraries kept as hex (cannot consume CSS variables).

6. FontAwesome replaced by Lucide. lucide-vue-next installed, 53 FA icons replaced. Zero FA references remaining.

7. Flat navbar. Gradient removed. Solid accent background, aligned with tech-utility direction.

8. Next: Mobile Flutter. Convert tokens to hex for genie-ai-config.json.
