- (decision) AD-1 [ADOPTED] Logging transport paradigm — Winston logger emits through Console (always) + VictoriaLogsTransport (OTel LoggerProvider, default on) + DailyRotateFile (gated on LOG_TO_FILE=1). Single Winston pipeline; new transport is a TransportStream subclass. Binds: producer/consumer schema stability; new transports do not bypass OTel resource attributes. Prevents: ad-hoc transports bypassing the OTel context.
- (decision) AD-2 [ADOPTED] VL stream fields pinned to {service.name, deployment.environment} only. trace_id/span_id are attributes, never stream fields. Binds: VL storage cardinality bounded. Prevents: VL cardinality blowup if trace_id were ever treated as stream field.
- (decision) AD-3 [ADOPTED] VictoriaLogsClient._normalizeRows shape is the canonical consumer contract: {timestamp, message, stream, fields, date, time, level, service}. Both LogsService and securityScanService depend on it. Binds: response shape stability for admin endpoints + scan responses. Prevents: two consumers diverging on row shape.
- (decision) AD-4 [ADOPTED] PII scrubbing applies to BOTH OTel span attributes (existing PIIRedactionProcessor at tracing.js:52-96) AND OTel log record body field (new PIIRedactingLogRecordProcessor). Do not reuse SpanProcessor pattern for LogRecord — different lifecycle (onEnd vs onEmit). Binds: PII never escapes to VL queryable by admin role. Prevents: email/JWT/password leaks via logger.info(`Login failed for ${email}`)
- (decision) AD-5 [ADOPTED] Dual-emit window (P1a→P1c overlap) handled by read-side filter in LogsService.getLogsInRange: service:genie-backend AND NOT _stream:genie.backend. Filter removed in P1c MR. Lint rule: forbid *fluent-logging anchor for js-runtime services post-P1c. Binds: no duplicate log records in admin UI. Prevents: 2x cost storage + double-counted security-scan vulnerabilities.
- (decision) AD-6 [ADOPTED] D2 escape hatch: ADMIN_LOGS_SOURCE=file|victorialogs is permanent. LogsService reads env PER-CALL inside getLogs/getLogsSummary/searchLogs/getDebugYesterday — NOT at module load. SECURITY_SCAN_BACKEND=file same pattern. Binds: no-restart rollback. Prevents: rollback matrix lying (env flip without restart).

LOG_TO_VICTORIALOGS=1 still gated on ENABLE_OBSERVABILITY=1 (so disabled observability does not emit into absent collector). Binds: admin endpoints functional independent of observability toggle. Prevents: cloud deployments with ENABLE_OBSERVABILITY=0 returning empty admin logs by policy.
- (decision) AD-8 [ADOPTED] OTel global setter pattern: use logs.setGlobalLoggerProvider(provider) from tracing.js init. NO custom setOtelLoggerProvider setter in shared/lib/logger.js. Binds: multi-process init does not last-wins collide between backend and document-repository. Prevents: doc-repo logs flowing through backend's LoggerProvider with backend's resource attributes.
- (decision) AD-9 [ADOPTED] Winston format = JSON (winston.format.combine(timestamp(), errors({stack:true}), json())). Replaces printf + traceFormat at logger.js:24-30. trace_id/span_id become JSON keys, not printf substrings. Binds: structured fields round-trip cleanly to OTel LogRecord attributes AND to file-fallback NDJSON parser. Prevents: F4 regex mismatch; OTel transport needing printf substring parsing.
- (decision) AD-10 [ADOPTED] File rotation + concurrent-writer invariants for ADMIN_LOGS_SOURCE=file fallback: re-read directory listing before each file; tolerate ENOENT between stat() and open() during DailyRotateFile rename. Concurrent writers (backend + doc-repo + future Node services on same path) use O_EXCL PID lock OR tail-style fadvise(FADV_SEQUENTIAL). NDJSON parse wraps JSON.parse in try/catch; on SyntaxError (truncated line from kill -9) read next N bytes and re-parse, else skip with parse_error counter. error.stack newline handled via winston.format.json({replacer}) or line-joining guard. Binds: file-fallback never throws ENOENT, never corrupts NDJSON. Prevents: empty logs after crash; torn-line throws.
- (decision) AD-11 [ADOPTED] Rate-limit state persistence: VL outage error logs capped at 1/min, state persisted to /tmp/vl-fail-open-ts so backend restarts do not reset the counter. Binds: restart loops do not flood backend logs. Prevents: 1-per-minute-cadence becoming 1-per-restart during extended outage.
- (decision) AD-12 [ADOPTED] /app/data/security/last-scan-results.json schema-validated on read. If schema does not match the new VL shape, treat as cache miss and regenerate.
