## Mission

The **Contribute** section is everything you need to **land a change** in
GENIE.AI: where the code lives, how to run the test suite locally, how to
open a merge request, and how to triage the next CVE. It is the steward
handoff — read once at the start of your first contribution, then keep it
open in a tab.

## If you are…

- **Opening your first MR** →
  [How to open a MR](/docs/contribute/how-to-mr/) — branch policy, MR template,
  CI gates.
- **Setting up a dev environment** →
  [Dev workflow](/docs/contribute/dev-workflow/) — env, lint, test, debug.
- **Finding where to put a new file** →
  [Repo layout](/docs/contribute/repo-layout/) — the full module map.
- **Adding a doc to this site** →
  [Add a new doc](/docs/contribute/add-a-doc/) — Docsy frontmatter, mode badge,
  weight.
- **Cutting a release** →
  [Release process](/docs/contribute/release-process/) — tag, changelog,
  publish.
- **Adding a translation** →
  [i18n contribution](/docs/contribute/i18n/) — key parity rules.
- **Triaging a CVE finding** →
  [Security triage](/docs/contribute/security-triage/) — triple-source
  verification playbook.
- **Writing prose that follows house style** →
  [Style guide](/docs/contribute/style-guide/) — language policy, voice,
  code-block rules.
