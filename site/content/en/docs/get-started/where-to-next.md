## Pick the persona you came in as

### I am an end user

You are done — sign in and chat. Two pages are worth bookmarking:

- **[Glossary](/docs/get-started/glossary/)** — for when the docs use an
  acronym you don't recognise.
- **[FAQ](/docs/get-started/faq/)** — for the 12 questions new users ask.

### I am a deployer

You have a running stack. The next page to read is:

- **[Deploy → Choose your deployment mode](/docs/deploy/install-guide/)** —
  promotes you from local Compose to production.
- **[Deploy → Configuration reference](/docs/reference/env-vars/)** — the single
  source of truth for every env-var.

Then move into day-to-day:

- **[Operate → Backup & restore](/docs/operate/backup-restore/)**
- **[Operate → Updates](/docs/operate/updates/)**
- **[Operate → Troubleshooting](/docs/operate/troubleshooting/)**

### I am a developer

You have the backend running locally. The next pages are:

- **[Backend → API contracts](/docs/backend/api-contracts-backend/)** — every public
  HTTP endpoint.
- **[RAG pipeline → Pipeline architecture](/docs/rag-pipeline/pipeline/)** —
  every OPEA microservice and its contract.
- **[Architecture → OPEA microservices](/docs/architecture/opea-microservices/)** —
  the service registry and protocol extensions.

For test / lint / CI:

- **[Contribute → Dev workflow](/docs/contribute/dev-workflow/)**

### I am a contributor

You have opened your first MR. Next:

- **[Contribute → How to open a MR](/docs/contribute/how-to-mr/)** — the
  full checklist.
- **[Contribute → Style guide](/docs/contribute/style-guide/)** — language
  policy, voice, code-block rules.
- **[Contribute → i18n](/docs/contribute/i18n/)** — add a translation.
- **[Contribute → Security triage](/docs/contribute/security-triage/)** —
  CVE playbook.
