# breaks the tokenizer: loading the baked-in NER model raises
#   OverflowError: Python int too large to convert to C ssize_t
# from Tokenizer._flush_specials, so every scan 500s. Bisected: 3.0.13 loads
# the same model bytes with the same spaCy, numpy and thinc; 3.0.14 does not.
# Nothing else in the stack differs between the two. Pinned until upstream
# ships a fix — this is the ONLY transitive pin, and it is load-bearing.
