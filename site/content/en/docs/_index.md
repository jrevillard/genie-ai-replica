# GENIE.AI Documentation

Sovereign, DPG-compliant generative AI / RAG framework for the public sector.
Multilingual retrieval-augmented generation, integrated with OPEA (Open Platform
for Enterprise AI), built for government and public-sector deployments.

## Start here

New to GENIE.AI? Read in this order:

1. [Project Overview](/docs/core/project-overview/) — what GENIE.AI is and why it exists
2. [Development Guide](/docs/core/development-guide/) — set up a local dev environment
3. [Docker Compose Setup](/docs/deployment/docker-compose-setup/) — single-node deployment
4. [Architecture Overview](/docs/architecture/architecture/) — C4 container view of the system

## Guides vs. Reference

- **Guides** walk through a task end-to-end (e.g. *Docker Compose Setup*,
  *Development Guide*).
- **Reference** describes the system as it exists (e.g. *Architecture Overview*,
  *API Contracts*, *UI Component Inventories*).
