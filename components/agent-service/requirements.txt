# GENIE.AI agent service — fully pinned dependency tree.
#
# Every version is pinned (not just the top-level ones) so the licence audit
# (V07a) covers EXACTLY what ships in the image: an audit of "whatever pip
# resolved on the day" is not an audit of a deployed artifact. Regenerate
# with:
#
#   uv pip compile <top-level pins> --python-version 3.11
#
# The top-level intent:
#   fastapi                              — the HTTP framework (as pii-service)
#   uvicorn                              — the ASGI server (as the OPEA overlay)
#   opentelemetry-api/sdk                — the tracing/metrics SDK
#   opentelemetry-exporter-otlp-proto-http — OTLP/HTTP export to the collector
#   opentelemetry-instrumentation-fastapi — FastAPI request spans
#   pydantic                              — the typed document capability contract
#   python-arango                         — the ArangoDB driver (search_knowledge adapter, story 1.6)
#   httpx                                 — the async TEI calls (embed + rerank); promoted from
#                                            the test tree (same audited pin, story 1.6)
#   kneed                                 — the knee_threshold selection strategy; the SAME pin
#                                            the deployed reranker serves (behavior frozen to V02)
#   langdetect                            — the language detection of the preparation module
#                                            (story 1.8); the SAME pin the deployed overlay
#                                            serves (dataprep requirements-cpu.txt), unseeded in
#                                            production exactly as deployed
#   six                                   — langdetect's tree (its only dependency)
#   numpy / scipy                         — kneed's tree (scipy) + the adaptive selection math;
#                                            numpy pinned to the deployed reranker's 1.26.4
#
# Licence + defaults audit for every pin: docs/dependencies/agent-service-dependency-evidence.json
# (procedure: docs/dependencies/pre-adoption-checklist.md).
