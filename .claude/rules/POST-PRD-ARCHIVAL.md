# Post-PRD Initiative Archival (stub)

Full procedure: `docs/post-prd-archival.md` — when a completed BMAD
initiative is archived before the next one starts
(`_bmad-output/archived/<initiative-key>/`), what moves, what stays.

Hard rules: archive on `main`, never from a worktree; keep
`deferred-work.md` in place (cross-initiative backlog, not a completed
artifact); keep shared `research/` in place; never rename files inside
the archive.
