This walkthrough introduces GENIE.AI through a public-service example. It
covers the RAG pipeline, OKF knowledge governance, observability and
deployment.

[Open the animated presentation](/presentations/genie-ai/index.html)

A 30-minute version tells the same story without the OKF tooling, the web
and mobile screens, the retrieval, reranking and generation detail, the
observability and troubleshooting slides, the testing-lab slide, the GPU
API and sizing slides and the deployment matrix.

[Open the 30-minute presentation](/presentations/genie-ai-30/index.html)

Use the arrow keys to navigate and advance diagram animations. Select
**Speaker notes** or press **S** to open the presenter view, which shows the
current slide, the next one, the notes and a clock.
Select **Pause motion** or press **M** to stop animations while presenting.
Use the language selector in the top-right corner to switch the deck between
the six United Nations languages. The language stays in the address, so a
link carries it.
