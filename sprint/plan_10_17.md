## Recon map (done 10-19 — specs must NOT re-walk this)

Upstream `main` has two complementary eval toolchains plus a parameter chooser:

| Upstream asset | What it does | Cost |
|---|---|---|
| `tests/rag-benchmarks/eval/run_eval.py anchor` | queries live chatqna with the gold dataset, harvests `reranker_selection` OTel spans, scores recall@k / precision / ndcg vs gold chunks | ~28 min / 42 queries |
| `run_eval.py dump-tuples` → `run_ragas_eval.py` | exports (question, answer, contexts, reference) tuples → RAGAS 0.4.3: faithfulness, context_precision, context_recall, answer_relevancy — judged by an EXTERNAL OpenAI-compatible LLM (sovereign: only exported tuples leave; runs locally, never in the deployment) | slow, needs judge |
| `eval/calibrate.py` | **the parameter chooser**: replays the logged per-candidate breakdown, sweeps CONTEXT_DECAY_FACTOR × confusion-formula × MIN_VALUE_THRESHOLD (hundreds of combos in seconds, no redeploy), ranks by F1, paired-bootstrap CI, `--check-baseline` validates replay vs live | seconds |
| `tests/run_rag_config_test_async.py` + `run_hybrid_tests.sh` | live grid sweep: k{5,15,30} × fetch_k{30,50} × search_start{chunk,edge,node} × traversal{off, depth 1-2, returned 2-5, thresh 0.5-0.7} × rerank{slice/threshold/knee_threshold × top_n/threshold} → per-config CSV (status, latency, answer) for human review | hours |
| `eval/enrich_xlsx_v2.py` | workbook: per-run tabs + Compare (delta vs baseline) + Calibrate (top-50 by F1) + Charts | offline |
| rag-benchmarks `benchmark_*.py` + `run_benchmarks.sh` + `GENIE-AI-Model-Test-Plan.md` | model/labeling/translation matrix per GPU profile; accuracy = key-terms + reference scoring; perf = load test | live |
| `eval/capture_baseline.py` | N-run parity baseline (min/median/max + tolerance) | live × N |

Gold flow: `xlsx_to_gold.py` (Phase 1) → `match_gold_chunks.py` (Phase 2,
content_hash identity, survives re-ingest) → anchor / dump-tuples → ragas →
enrich. Gold dataset is corpus-independent once built. Operational docs:
`eval/CLAUDE.md` (entry), `eval/RUNBOOK.md` (Phase 0–5).

Local state (verified 10-19): `tests/` holds the OLD sync sweep
